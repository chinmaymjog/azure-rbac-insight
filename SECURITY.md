# Security Policy

This tool processes Azure RBAC data (role assignments, scopes, principals) that
can be sensitive. It is designed to run locally and keep data on the user's machine.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting:
<https://github.com/chinmaymjog/azure-rbac-insight/security/advisories/new>

Never attach real tenant exports, credentials, or tokens to issues or PRs; use
redacted or synthetic samples.

You can expect an initial response within a few days.

## Supported versions

Only the latest `main` receives security fixes.
